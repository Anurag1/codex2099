Evaluation integrity

TRANSPARENT

A fair comparison holds the input, provider model, generation settings and rubric constant. Repeated trials expose variability. Prompt Arena reports sample count, mean score, standard deviation, latency and token usage where available.

A higher heuristic score is not proof of a better answer. Use labelled test cases and independent human review before making production decisions.

Local setup

Create a local .env file from .env.example inside apps/prompt-arena, add the provider keys you own, then start the Node.js server. Do not paste API keys into this UI or commit them to Git.

cp .env.example .env
npm start
